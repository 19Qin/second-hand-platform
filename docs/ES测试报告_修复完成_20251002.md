## 🐛 Bug修复记录

### 问题: 价格降序排序未生效

**发现时间**: 2025-10-02 02:15
**问题描述**: `sortBy=price_desc` 返回与 `price_asc` 相同的结果
**根本原因**: 代码支持两种格式参数,但未正确解析组合格式 `sortBy=price_desc`

**修复方案**:

修改文件: `src/main/java/com/fliliy/secondhand/service/ProductSearchService.java`

```java
// 修复前: 只支持分离格式 sortBy=price&sortOrder=desc
String sortBy = request.getSortBy();
String sortOrder = request.getSortOrder();

// 修复后: 支持两种格式
// 1. sortBy=price_asc 或 sortBy=price_desc (组合格式)
// 2. sortBy=price&sortOrder=asc (分离格式)
String sortBy = request.getSortBy() != null ? request.getSortBy() : "publishedAt";
String sortOrder = request.getSortOrder() != null ? request.getSortOrder() : "desc";

// 如果sortBy包含下划线,解析为字段和方向
if (sortBy.contains("_")) {
    String[] parts = sortBy.split("_", 2);
    sortBy = parts[0];
    sortOrder = parts.length > 1 ? parts[1] : "desc";
    log.info("解析后排序参数 - sortBy: {}, sortOrder: {}", sortBy, sortOrder);
}
```

**修复结果**: ✅ 已验证

**测试验证**:
```bash
# 价格降序 (高到低)
curl "http://localhost:8080/api/v1/products/search?sortBy=price_desc"
结果: MacBook Pro (¥8999) → 小米13 (¥3299) → 测试商品 (¥100) ✓

# 价格升序 (低到高)
curl "http://localhost:8080/api/v1/products/search?sortBy=price_asc"
结果: 测试商品 (¥100) → 小米13 (¥3299) → MacBook Pro (¥8999) ✓
```
