## 问题与建议

### 发现的问题

#### 1. 价格降序排序未生效 🔴 高优先级
**问题描述**: sortBy=price_desc 返回与 price_asc 相同的结果

**影响范围**: 排序功能

**建议修复**: 
1. 检查 ProductSearchService.java:XXX 行的排序逻辑
2. 验证 SortOrder 枚举是否正确设置
3. 添加单元测试覆盖排序场景

**修复代码建议**:
```java
// 可能的问题位置
if ("price_desc".equals(sortBy)) {
    searchSourceBuilder.sort("price", SortOrder.DESC); // 确保这里是DESC而不是ASC
}
```

### 优化建议

#### 1. 性能优化 🟡 中优先级
- 当前数据量小(5条),建议添加更多测试数据(1000+)进行压力测试
- 考虑添加缓存层,缓存热门搜索结果

#### 2. 功能增强 🟢 低优先级
- 添加按浏览量、收藏量排序
- 实现综合排序(相关度 + 时间 + 热度)
- 支持拼音搜索(如搜索"shouji"匹配"手机")

#### 3. 监控告警 🟢 低优先级
- 配置慢查询告警(>100ms)
- 监控ES集群健康状态
- 统计搜索热词Top10
