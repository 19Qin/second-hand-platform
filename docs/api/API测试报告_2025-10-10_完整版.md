## 1. 认证模块 (AuthController)

### 1.1 发送验证码 ✅
**接口**: `POST /auth/sms/send`
**状态**: 通过
**限流**: 1分钟内只能发送1次(IP限流)

**请求示例**:
```bash
curl -X POST http://localhost:8080/api/v1/auth/sms/send \
  -H "Content-Type: application/json" \
  -d '{
    "mobile": "13800138000",
    "type": "login"
  }'
```

**响应示例**:
```json
{
  "code": 200,
  "message": "验证码发送成功",
  "data": {
    "smsId": "sms_20251010195454_192",
    "expireTime": 300
  },
  "timestamp": 1760097294473
}
```

**响应字段说明**:
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| code | Number | 是 | 状态码,200表示成功 |
| message | String | 是 | 提示信息 |
| data.smsId | String | 是 | 短信ID,登录时需要 |
| data.expireTime | Number | 是 | 过期时间(秒),固定300秒 |
| timestamp | Number | 是 | 服务器时间戳 |

**注意事项**:
- ⚠️ type必须小写: `login` / `register` / `reset`
- 验证码5分钟有效
- 验证码会在日志中打印(开发环境)

---

### 1.2 验证码登录 ✅
**接口**: `POST /auth/login/sms`
**状态**: 通过

**请求示例**:
```bash
curl -X POST http://localhost:8080/api/v1/auth/login/sms \
  -H "Content-Type: application/json" \
  -d '{
    "mobile": "13800138000",
    "smsCode": "5379",
    "smsId": "sms_20251010195454_192"
  }'
```

**响应示例**:
```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "userId": "1959106057909440512",
    "username": "testuser1",
    "mobile": "13800138000",
    "email": null,
    "avatar": "https://cdn.fliliy.com/avatar/default.png",
    "accessToken": "eyJhbGciOiJIUzI1NiJ9...",
    "refreshToken": "eyJhbGciOiJIUzI1NiJ9...",
    "expiresIn": 7200,
    "needBindMobile": false
  },
  "timestamp": 1760097395024
}
```

**响应字段说明**:
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| userId | String | 是 | 用户ID |
| username | String | 是 | 用户名 |
| mobile | String | 是 | 手机号 |
| avatar | String | 是 | 头像URL |
| accessToken | String | 是 | 访问令牌,有效期2小时 |
| refreshToken | String | 是 | 刷新令牌,有效期15天 |
| expiresIn | Number | 是 | 访问令牌过期时间(秒) |

**注意事项**:
- accessToken用于API调用,放在Header的Authorization中
- 格式: `Authorization: Bearer {accessToken}`
- Token过期后使用refreshToken刷新

## 🎯 关键发现和注意事项

### 1. ID类型不一致
| 接口 | ID类型 | 示例 |
|------|--------|------|
| 商品列表 | String | "1969761981678358528" |
| 商品搜索 | Number | 1968947273484341200 |
| 交易ID | String | "tx_1976621912847159296" |

**建议**: 前端统一转换为String处理

### 2. 分页数据结构统一
✅ 所有分页接口统一使用以下结构:
```javascript
response.data.content        // 数据数组
response.data.pagination     // 分页信息
```

❌ 常见错误:
```javascript
response.data.products       // ✗ 不存在
response.data.items          // ✗ 不存在
```

### 3. 时间格式统一
- 统一格式: `yyyy-MM-dd HH:mm:ss`
- 时区: Asia/Shanghai (UTC+8)
- 示例: `"2025-10-10 20:12:43"`

### 4. Token使用
- Header格式: `Authorization: Bearer {accessToken}`
- 有效期: 2小时
- 刷新: 使用refreshToken

### 5. 中文支持
- ✅ 请求和响应完全支持中文
- 编码: UTF-8
- 无需特殊处理
