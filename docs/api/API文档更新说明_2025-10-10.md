## ⚠️ 重要提醒

### 1. 字段类型要特别注意

从真实数据中发现的类型差异:

| 字段 | 预期类型 | 实际类型 | 接口 |
|------|---------|---------|------|
| id | Number | **String** | 商品列表 |
| price | String | **Number** | 所有商品接口 |
| hasWarranty | String | **Boolean** | 商品详情 |
| isFavorited | String | **Boolean** | 商品统计 |
| hasNext | String | **Boolean** | 分页信息 |

**建议**: 前端统一做类型转换,不要直接假设类型

### 2. 数据结构要仔细核对

| 错误假设 | 实际情况 |
|---------|---------|
| `response.data.products` | ❌ 不存在,应该是 `response.data.content` |
| `response.data.items` | ❌ 不存在,应该是 `response.data.content` |
| `response.data.transactions` | ⚠️ 交易接口是例外,用的是transactions |

### 3. 时间格式统一

所有时间字段格式: `yyyy-MM-dd HH:mm:ss`
- 示例: `"2025-09-21 21:53:47"`
- 时区: Asia/Shanghai (UTC+8)
