## ⚠️ 重要注意事项

### 1. ID类型不一致
- 商品列表: String类型 `"1969761981678358528"`
- 搜索接口: Number类型 `1969761981678358528`
- **建议**: 前端统一转为String处理

### 2. 分页数据结构
```javascript
// ✅ 正确
response.data.content      // 数据列表
response.data.pagination   // 分页信息

// ❌ 错误
response.data.products     // 不存在
response.data.items        // 不存在
```

### 3. 交易ID格式
- 格式: `"tx_1976621912847159296"`
- API调用时可使用完整格式或纯数字

### 4. 聊天室新增字段
- `activeTransactions`: 包含所有进行中的交易
- 每个交易包含完整的商品信息和状态
- 替代原有的单一 `transactionId` 字段
