## 六、发现的问题

### 问题1: 聊天室列表中的transactionId始终为null ⚠️

**描述**:
- 聊天室列表响应中有`transactionId`字段
- 但该字段始终为`null`，即使该聊天室有进行中的交易

**影响**:
- 前端无法通过聊天室列表直接获取当前交易ID
- 需要通过聊天消息或交易列表来获取transactionId

**建议**:
- 如果该字段用于显示聊天室的当前交易，建议关联最新的PENDING或AGREED状态的交易ID
- 或者移除该字段，避免前端误用
