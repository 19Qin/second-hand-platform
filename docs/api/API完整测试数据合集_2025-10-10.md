## 1. 认证模块

### 1.1 发送验证码

**接口**: `POST /auth/sms/send`

**请求示例**:
```bash
curl -X POST http://localhost:8080/api/v1/auth/sms/send \
  -H "Content-Type: application/json" \
  -d '{
    "mobile": "13800138000",
    "type": "login"
  }'
```

**真实响应**:
```json
{
  "code": 200,
  "message": "验证码发送成功",
  "data": {
    "smsId": "sms_20251010195454_192",
    "expireTime": 300
  },
  "timestamp": 1760097294473
}
```

**字段说明**:
| 字段 | 类型 | 说明 |
|------|------|------|
| data.smsId | String | 短信ID,登录时需要传递 |
| data.expireTime | Number | 过期时间(秒),固定300秒 |

**注意事项**:
- ⚠️ type必须小写: `login` / `register` / `reset`
- 验证码会在后端日志中打印(开发环境)
- 1分钟内同一IP只能发送1次(限流)
