### 4. Redis缓存策略实现 (100%)

**新增文件:** `src/main/java/com/fliliy/secondhand/service/CacheService.java`

**核心功能:**
```java
@Service
public class CacheService {
    // 商品详情缓存 (5分钟)
    @Cacheable(value = "products", key = "'detail:' + #productId")
    public ProductDetailResponse getProductDetailCached(Long productId, Long userId);

    // 用户信息缓存 (30分钟)
    @Cacheable(value = "users", key = "'profile:' + #userId")
    public UserProfileResponse getUserProfileCached(Long userId);

    // 分类树缓存 (6小时)
    @Cacheable(value = "categories", key = "'tree'")
    public List<Category> getCategoryTreeCached();

    // 缓存清除方法
    @CacheEvict(value = "products", key = "'detail:' + #productId")
    public void evictProductCache(Long productId);
}
```

**修改文件:** `src/main/java/com/fliliy/secondhand/config/CacheConfig.java`

**缓存TTL配置:**
- 商品详情: 5分钟 (变化较频繁)
- 用户信息: 30分钟 (较稳定)
- 分类树: 6小时 (很少变化)
- 聊天室列表: 30秒 (实时性高)
