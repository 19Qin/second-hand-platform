## 💡 重要提醒

### 错误码使用规范
```java
// ✅ 推荐写法
throw new BusinessException(ErrorCode.USER_NOT_FOUND);

// ✅ 带自定义消息
throw new BusinessException(ErrorCode.SYSTEM_ERROR, "详细错误信息");

// ❌ 不推荐 (除非没有对应的ErrorCode)
throw new RuntimeException("用户不存在");
```

### 日志使用规范
```java
// DEBUG: 详细执行过程
log.debug("Starting to process product: productId={}", productId);

// INFO: 业务操作记录
log.info("User logged in: userId={}, ip={}", userId, ip);

// WARN: 业务异常、限流告警
log.warn("Invalid login attempt: userId={}", userId);

// ERROR: 系统异常、未知错误
log.error("Failed to save product: ", exception);
```

### 参数校验最佳实践
```java
// Controller层: 使用@Valid或@Validated触发校验
@PostMapping("/register")
public ApiResponse<AuthResponse> register(@Valid @RequestBody RegisterRequest request) {
    // 校验失败会被GlobalExceptionHandler捕获
}

// DTO层: 添加校验注解
public class RegisterRequest {
    @NotBlank(message = "手机号不能为空")
    @ValidPhoneNumber(message = "手机号格式不正确")
    private String mobile;

    @NotBlank(message = "密码不能为空")
    @Size(min = 6, max = 20, message = "密码长度6-20位")
    private String password;
}
```
