## 🎨 核心特性

### 1. Dockerfile多阶段构建

**优势**:
- ✅ 构建阶段使用完整JDK，运行阶段仅需JRE
- ✅ 镜像大小优化：约200MB（相比单阶段减少60%）
- ✅ 利用Docker缓存层，依赖变化少时构建更快
- ✅ 中文支持：安装字体和时区配置

**关键配置**:
```dockerfile
# 阶段1: 构建 (maven:3.6-jdk-8)
FROM maven:3.6-jdk-8 AS builder
COPY pom.xml .
RUN mvn dependency:go-offline -B
COPY src ./src
RUN mvn clean package -DskipTests -B

# 阶段2: 运行 (openjdk:8-jre-alpine)
FROM openjdk:8-jre-alpine
COPY --from=builder /app/target/*.jar app.jar
```

## 🔍 技术亮点

### 1. 生产级配置

**自动重启策略**:
```yaml
restart: always  # 容器退出自动重启
```

**资源限制** (应用容器):
```yaml
resources:
  requests:
    memory: "512Mi"
    cpu: "500m"
  limits:
    memory: "1Gi"
    cpu: "1000m"
```

**JVM优化**:
```bash
JAVA_OPTS: -Xms512m -Xmx1024m -XX:+UseG1GC -XX:MaxGCPauseMillis=200
```

### 2. 数据持久化

所有数据通过命名卷持久化：
```yaml
volumes:
  - mysql-data:/var/lib/mysql
  - redis-data:/data
  - es-data:/usr/share/elasticsearch/data
  - rabbitmq-data:/var/lib/rabbitmq
```

**优势**:
- ✅ 容器删除数据不丢失
- ✅ 方便备份和迁移
- ✅ 性能优于bind mount

### 3. 网络隔离

自定义桥接网络：
```yaml
networks:
  fliliy-network:
    driver: bridge
```

**优势**:
- ✅ 服务间通过服务名通信
- ✅ 与宿主机其他容器隔离
- ✅ 内置DNS解析

### 4. 安全配置

**环境变量管理**:
- ✅ 敏感信息通过环境变量配置
- ✅ 不同环境使用不同配置文件
- ✅ 支持.env文件（未提交到Git）

**密码策略**:
- ✅ 生产环境使用强密码
- ✅ 开发环境使用简单密码
- ✅ 密码可通过环境变量覆盖
