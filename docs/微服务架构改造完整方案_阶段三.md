## 📦 服务拆分方案

### 服务列表

| 服务名 | 端口 | 职责 | 数据库 | 依赖服务 |
|-------|------|------|--------|---------|
| **fliliy-gateway** | 9000 | API网关、路由、限流、认证 | - | Nacos, Redis |
| **fliliy-auth** | 8001 | 用户认证、JWT、短信验证 | auth_db | Redis |
| **fliliy-user** | 8002 | 用户信息、地址、通知 | user_db | - |
| **fliliy-product** | 8003 | 商品管理、分类、收藏 | product_db | RabbitMQ |
| **fliliy-search** | 8004 | Elasticsearch搜索 | ES | RabbitMQ |
| **fliliy-chat** | 8005 | WebSocket聊天、消息 | chat_db | RabbitMQ |
| **fliliy-transaction** | 8006 | 交易管理、交易码 | transaction_db | RabbitMQ |
| **fliliy-file** | 8007 | 文件上传、图片处理 | 文件系统 | - |

### 服务详细设计

#### 1. fliliy-gateway (API网关) - Port 9000

```yaml
职责:
  - 统一入口 (所有外部请求的入口)
  - 路由转发 (根据路径转发到具体服务)
  - 统一认证 (JWT Token验证)
  - 限流熔断 (保护后端服务)
  - 跨域处理
  - 日志记录

技术栈:
  - Spring Cloud Gateway
  - Spring Cloud LoadBalancer
  - Redis (限流、黑名单)
  - JWT (Token验证)

关键配置:
  routes:
    - /api/v1/auth/** → fliliy-auth
    - /api/v1/users/** → fliliy-user
    - /api/v1/products/** → fliliy-product
    - /api/v1/search/** → fliliy-search
    - /api/v1/chats/** → fliliy-chat
    - /api/v1/transactions/** → fliliy-transaction
    - /api/v1/files/** → fliliy-file

白名单 (不需要认证):
  - /api/v1/auth/login
  - /api/v1/auth/register
  - /api/v1/auth/sms/send
  - /api/v1/products/search
  - /api/v1/products/{id}
```

#### 2. fliliy-auth (认证服务) - Port 8001

```yaml
职责:
  - 用户注册 (手机号 + 验证码)
  - 用户登录 (密码登录、验证码登录)
  - JWT Token生成和刷新
  - 短信验证码发送和验证
  - 第三方登录 (预留接口)

数据库: auth_db
  tables:
    - users (用户基本信息、密码)
    - user_tokens (Token记录)
    - verification_codes (验证码)
    - sms_records (短信发送记录)

依赖:
  - Redis: 验证码存储 (5分钟TTL)
  - Redis: Token黑名单

API:
  - POST /auth/register (注册)
  - POST /auth/login/password (密码登录)
  - POST /auth/login/sms (验证码登录)
  - POST /auth/sms/send (发送验证码)
  - POST /auth/token/refresh (刷新Token)
  - POST /auth/logout (登出)

对外提供 (Feign):
  - GET /internal/users/{userId} (获取用户信息 - 内部调用)
  - POST /internal/users/validate (验证用户 - 内部调用)
```

#### 3. fliliy-user (用户服务) - Port 8002

```yaml
职责:
  - 用户信息管理 (昵称、头像、个人简介)
  - 用户地址管理 (增删改查、默认地址)
  - 用户通知管理 (系统通知、消息推送)
  - 用户统计 (发布数、交易数)

数据库: user_db
  tables:
    - user_profiles (用户详细信息)
    - user_addresses (收货地址)
    - user_notifications (通知记录)

API:
  - GET /users/profile (获取个人信息)
  - PUT /users/profile (更新个人信息)
  - GET /users/{userId} (查看他人信息)
  - GET /users/addresses (地址列表)
  - POST /users/addresses (添加地址)
  - PUT /users/addresses/{id} (更新地址)
  - DELETE /users/addresses/{id} (删除地址)
  - GET /users/notifications (通知列表)
  - PUT /users/notifications/{id}/read (标记已读)

对外提供 (Feign):
  - GET /internal/users/{userId} (获取用户信息 - 供其他服务调用)
  - POST /internal/users/batch (批量获取用户信息)
```

#### 4. fliliy-product (商品服务) - Port 8003

```yaml
职责:
  - 商品发布、编辑、删除
  - 商品详情查询
  - 商品列表查询 (分页、筛选、排序)
  - 商品分类管理
  - 商品收藏管理
  - 商品事件发布 (通过RabbitMQ)

数据库: product_db
  tables:
    - products (商品信息)
    - categories (商品分类)
    - product_images (商品图片)
    - product_tags (商品标签)
    - product_favorites (商品收藏)

依赖:
  - RabbitMQ: 发布商品事件 (创建、更新、删除)
  - Redis: 商品详情缓存 (5分钟)
  - User Service (Feign): 获取用户信息

API:
  - POST /products (发布商品)
  - PUT /products/{id} (编辑商品)
  - DELETE /products/{id} (删除商品)
  - GET /products/{id} (商品详情)
  - GET /products (商品列表)
  - GET /products/my (我的商品)
  - POST /products/{id}/favorite (收藏商品)
  - DELETE /products/{id}/favorite (取消收藏)
  - GET /products/favorites (我的收藏)
  - GET /categories (分类列表)

对外提供 (Feign):
  - GET /internal/products/{id} (获取商品信息)
  - POST /internal/products/batch (批量获取商品)
  - PUT /internal/products/{id}/status (更新商品状态 - 内部调用)

MQ消息:
  - 发送: product.published (商品发布)
  - 发送: product.updated (商品更新)
  - 发送: product.deleted (商品删除)
```

#### 5. fliliy-search (搜索服务) - Port 8004

```yaml
职责:
  - Elasticsearch商品搜索
  - 中文分词搜索 (IK分词器)
  - 多条件筛选、排序
  - 搜索结果高亮
  - 搜索建议 (自动补全)
  - 热门搜索词统计
  - 商品数据同步 (监听MQ)

存储: Elasticsearch
  index:
    - products (商品索引)

依赖:
  - Elasticsearch: 搜索引擎
  - RabbitMQ: 监听商品事件，自动同步数据
  - Redis: 热门搜索词缓存

API:
  - GET /search/products (搜索商品)
  - GET /search/suggest (搜索建议)
  - GET /search/hot (热门搜索词)

内部API:
  - POST /internal/search/sync/{productId} (同步单个商品)
  - POST /internal/search/sync-all (全量同步)
  - DELETE /internal/search/{productId} (删除商品)

MQ消息:
  - 监听: product.published (同步新商品)
  - 监听: product.updated (更新商品)
  - 监听: product.deleted (删除商品)
```

#### 6. fliliy-chat (聊天服务) - Port 8005

```yaml
职责:
  - WebSocket实时聊天
  - 聊天室管理
  - 聊天消息存储
  - 未读消息统计
  - 消息推送 (离线消息)

数据库: chat_db
  tables:
    - chat_rooms (聊天室)
    - chat_messages (聊天消息)

依赖:
  - WebSocket: 实时通信
  - RabbitMQ: 消息推送
  - Redis: 在线用户、未读消息计数
  - User Service (Feign): 获取用户信息
  - Product Service (Feign): 获取商品信息

API:
  - POST /chats/product-discussion (开始商品讨论)
  - GET /chats (聊天列表)
  - GET /chats/{id}/messages (聊天记录)
  - POST /chats/{id}/messages (发送消息)
  - POST /chats/{id}/read (标记已读)
  - POST /chats/messages/{id}/recall (撤回消息)

WebSocket:
  - /ws/chat (WebSocket连接端点)
  - /topic/chat/{roomId} (聊天室订阅)
  - /user/queue/messages (个人消息队列)

MQ消息:
  - 发送: notification.new_message (新消息通知)
```

#### 7. fliliy-transaction (交易服务) - Port 8006

```yaml
职责:
  - 交易申请 (买家发起)
  - 交易响应 (卖家同意/拒绝)
  - 线下交易流程
  - 交易码生成和验证
  - 交易完成确认
  - 交易记录查询

数据库: transaction_db
  tables:
    - transactions (交易记录)

依赖:
  - RabbitMQ: 交易事件
  - Redis: 交易码缓存 (30分钟)
  - Product Service (Feign): 获取商品信息、更新商品状态
  - User Service (Feign): 获取用户信息

API:
  - POST /transactions/inquiry (发起交易咨询)
  - POST /transactions/request (发起交易申请)
  - POST /transactions/{id}/respond (响应交易申请)
  - POST /transactions/{id}/agree-offline (同意线下交易)
  - POST /transactions/{id}/complete (完成交易)
  - POST /transactions/{id}/cancel (取消交易)
  - GET /transactions (交易记录)
  - GET /transactions/{id} (交易详情)

MQ消息:
  - 发送: transaction.completed (交易完成)
  - 发送: transaction.cancelled (交易取消)
  - 发送: notification.transaction_* (交易通知)
```

#### 8. fliliy-file (文件服务) - Port 8007

```yaml
职责:

存储: 本地文件系统 / OSS (可扩展)

依赖:

API:
```

## 🗄️ 数据库拆分方案

### 拆分策略

```yaml
原则:
  ✅ 按业务边界拆分
  ✅ 减少跨库关联查询
  ✅ 保留必要的数据冗余
  ✅ 通过服务调用获取关联数据

拆分方式: 垂直拆分
  - 每个服务独立数据库
  - 服务间不直接访问对方数据库
```

### OpenFeign接口定义

#### UserFeignClient (被多个服务调用)

```java
@FeignClient(name = "fliliy-user", path = "/api/v1/internal/users")
public interface UserFeignClient {

    /**
     * 获取用户信息
     */
    @GetMapping("/{userId}")
    ApiResponse<UserDTO> getUserById(@PathVariable("userId") Long userId);

    /**
     * 批量获取用户信息
     */
    @PostMapping("/batch")
    ApiResponse<List<UserDTO>> getUsersByIds(@RequestBody List<Long> userIds);

    /**
     * 验证用户存在
     */
    @GetMapping("/{userId}/exists")
    ApiResponse<Boolean> checkUserExists(@PathVariable("userId") Long userId);
}
```

#### ProductFeignClient (被多个服务调用)

```java
@FeignClient(name = "fliliy-product", path = "/api/v1/internal/products")
public interface ProductFeignClient {

    /**
     * 获取商品信息
     */
    @GetMapping("/{productId}")
    ApiResponse<ProductDTO> getProductById(@PathVariable("productId") Long productId);

    /**
     * 批量获取商品信息
     */
    @PostMapping("/batch")
    ApiResponse<List<ProductDTO>> getProductsByIds(@RequestBody List<Long> productIds);

    /**
     * 更新商品状态 (内部调用)
     */
    @PutMapping("/{productId}/status")
    ApiResponse<Void> updateProductStatus(
        @PathVariable("productId") Long productId,
        @RequestParam("status") String status
    );
}
```

## ⚠️ 风险评估

### 技术风险

| 风险 | 可能性 | 影响 | 应对策略 |
|-----|-------|------|---------|
| **服务调用失败** | 中 | 高 | 实现Fallback降级、重试机制 |
| **分布式事务** | 高 | 高 | 尽量避免、使用最终一致性 |
| **网络延迟** | 中 | 中 | 优化服务调用、使用缓存 |
| **配置错误** | 低 | 高 | Nacos配置备份、测试环境验证 |
| **数据迁移失败** | 低 | 高 | 数据备份、灰度迁移 |

### 应对措施

```yaml
服务容错:
  ✅ Feign超时配置 (3秒)
  ✅ 重试机制 (最多3次)
  ✅ 熔断降级 (Sentinel/Resilience4j)
  ✅ 服务降级返回默认值

数据一致性:
  ✅ 避免分布式事务
  ✅ 使用消息队列保证最终一致性
  ✅ 幂等性设计
  ✅ 补偿机制

部署策略:
```
