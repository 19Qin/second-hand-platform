### Elasticsearch管理

```bash
# 查看集群健康
curl http://localhost:9200/_cluster/health?pretty

# 查看索引列表
curl http://localhost:9200/_cat/indices?v

# 查看products索引信息
curl http://localhost:9200/products?pretty

# 查看索引映射
curl http://localhost:9200/products/_mapping?pretty

# 查看索引数据量
curl http://localhost:9200/products/_count?pretty

# 删除products索引（慎用！）
curl -X DELETE http://localhost:9200/products

# 手动刷新索引
curl -X POST http://localhost:9200/products/_refresh
```

### 应用管理API

```bash
# 全量同步
curl -X POST "http://localhost:8080/api/v1/admin/elasticsearch/sync-all"

# 同步单个商品（ID=123）
curl -X POST "http://localhost:8080/api/v1/admin/elasticsearch/sync/123"

# 从ES删除商品（ID=123）
curl -X DELETE "http://localhost:8080/api/v1/admin/elasticsearch/delete/123"

# 清空ES索引
curl -X DELETE "http://localhost:8080/api/v1/admin/elasticsearch/clear"

# 重建索引（清空+全量同步）
curl -X POST "http://localhost:8080/api/v1/admin/elasticsearch/rebuild"
```

## 💡 重要提示

1. **ES容器状态**
   - 容器名：`fliliy-es`
   - 端口：9200（HTTP）、9300（TCP）
   - 每次重启电脑需要手动启动容器

2. **数据同步**
   - 商品创建/更新/删除会自动同步ES（通过事件监听器）
   - 首次启动需要执行全量同步
   - 如果数据不一致，可执行重建索引

3. **性能优化**
   - ES默认内存512MB（开发环境够用）
   - 生产环境建议2GB+
   - 可通过修改docker run的ES_JAVA_OPTS调整

4. **备份建议**
   - ES数据存储在Docker Volume
   - 建议定期备份MySQL数据（ES可随时重建）
