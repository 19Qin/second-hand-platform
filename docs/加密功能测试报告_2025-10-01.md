## 8. 使用示例

### 8.1 加密敏感数据

```java
@Autowired
private EncryptionUtil encryptionUtil;

// 加密身份证号
String idCard = "110101199001011234";
String encrypted = encryptionUtil.encrypt(idCard);
// 存储到数据库: encrypted

// 从数据库读取并解密
String decrypted = encryptionUtil.decrypt(encrypted);
// 使用明文: decrypted
```

### 8.2 脱敏显示

```java
// 接口返回时脱敏
UserResponse response = new UserResponse();
response.setPhone(encryptionUtil.maskPhone(user.getPhone()));
response.setIdCard(encryptionUtil.maskIdCard(user.getIdCard()));
response.setName(encryptionUtil.maskName(user.getName()));
```

### 8.3 日志输出脱敏
