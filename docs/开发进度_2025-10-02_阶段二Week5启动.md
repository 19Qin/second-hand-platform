## ✅ 已完成工作

### 1. 环境配置准备

#### Docker Compose配置
创建文件：`docker-compose-es.yml`
```yaml
version: '3.8'
services:
  elasticsearch:
    image: docker.elastic.co/elasticsearch/elasticsearch:7.17.10
    container_name: fliliy-es
    ports:
      - "9200:9200"
      - "9300:9300"
    environment:
      - discovery.type=single-node
      - "ES_JAVA_OPTS=-Xms512m -Xmx512m"
      - xpack.security.enabled=false
    volumes:
      - es-data:/usr/share/elasticsearch/data
      - es-plugins:/usr/share/elasticsearch/plugins
    healthcheck:
      test: ["CMD-SHELL", "curl -f http://localhost:9200/_cluster/health || exit 1"]
      interval: 30s
      timeout: 10s
      retries: 5

  kibana:
    image: docker.elastic.co/kibana/kibana:7.17.10
    container_name: fliliy-kibana
    ports:
      - "5601:5601"
    environment:
      - ELASTICSEARCH_HOSTS=http://elasticsearch:9200
      - I18N_LOCALE=zh-CN
    depends_on:
      - elasticsearch
```

**特点**：
- 单节点模式（适合开发环境）
- JVM堆内存设置为512MB（避免占用过多资源）
- 禁用X-Pack安全功能（简化开发）
- 配置了健康检查
- 数据持久化到Docker Volume

## 💡 关键技术点

### 1. IK分词器配置
- **ik_max_word**: 索引时使用，最细粒度拆分
  - 例："苹果手机" → [苹果, 手机, 苹果手机]
- **ik_smart**: 搜索时使用，粗粒度拆分
  - 例："苹果手机" → [苹果手机]

### 2. 字段类型选择
- **Text**: 需要全文搜索的字段（标题、描述）
- **Keyword**: 需要精确匹配、聚合、排序的字段（分类、状态、城市）
- **Double**: 数值范围查询（价格）
- **Date**: 日期范围和排序（发布时间）
- **GeoPoint**: 地理位置搜索（附近商品）

### 3. 数据冗余策略
为了避免搜索时的JOIN操作，冗余存储：
- 卖家昵称、头像
- 分类名称
- 主图URL

**权衡**: 空间换时间，提升搜索性能

### 4. 索引配置
```java
@Document(indexName = "products")
@Setting(shards = 1, replicas = 0)
```
- **shards = 1**: 单分片（开发环境，数据量小）
- **replicas = 0**: 无副本（开发环境，无需高可用）
- 生产环境建议：shards = 3~5, replicas = 1~2

## 🐛 潜在问题与解决方案

### 问题1: Docker镜像下载慢
**解决方案**:
- 使用国内镜像加速器（阿里云、DaoCloud）
- 或直接使用 `docker pull` 单独下载

### 问题2: ES容器启动失败（内存不足）
**错误信息**: `max virtual memory areas vm.max_map_count [65530] is too low`

**解决方案**:
```bash
# macOS (需要重启Docker Desktop)
sudo sysctl -w vm.max_map_count=262144

# Linux
sudo sysctl -w vm.max_map_count=262144
echo "vm.max_map_count=262144" | sudo tee -a /etc/sysctl.conf
```

### 问题3: IK分词器版本不匹配
**解决方案**:
- IK分词器版本必须与ES版本完全一致
- ES 7.17.10 → IK 7.17.10

### 问题4: 数据同步延迟
**解决方案**:
- 使用事件监听器自动同步
- 设置合理的ES refresh_interval
- 考虑使用消息队列（RabbitMQ）异步同步
